KDE DESKTOP RECIPE COVERAGE — 2026-10-25

Scope: stable desktop releases using Qt 6/KF6, as selected by the user.
Local repository: /sources/Voncloft-OS-dev. No package installation or live session change.
All 252 KDE Gear 26.08.2 source packages were already represented before this addition.
Added 43 independently released desktop app recipes and 34 supporting dependency recipes.
Updated 7 existing recipes and added the optional kde-desktop-apps-extra group.
Existing KDE build/install helpers are retained.

VALIDATION
New and version-updated primary source archives were downloaded and checked for their actual source-root names.
GCompris and Rolisteam explicitly include the exact submodule revisions from their stable tags.
Shell syntax and dependency closure checked: 85 changed/group recipes, 523 packages in the full chain, no unresolved dependency names or cycles.
CMake configure passed: krusader, ktimetracker, kdiff3, drawy, komodo, hash-o-matic, kodaskanna, klevernotes, kookbook, gcompris (including the teachers application), rolisteam.
KGeoTag configure reached its declared Marble dependency, which is not installed on the current host.
SQLCipher compiled and staged successfully; an encrypted database was created and reopened with its key and rejected without it.
SQLCipher stages distinct library/header/CLI/pkg-config names and does not replace system SQLite.
No full build or runtime test was performed for every application. In particular, the compiler add-on has not been compiled here.

PACKAGING CHOICES
gcc-fortran 15.1.0 adds only the Fortran frontend/runtime for the existing GCC 15.1.0; its recipe checks the compiler version before building.
It uses upstream Fortran-specific install targets plus f951, and does not install C/C++ drivers, libgcc, libstdc++, or libquadmath.
R uses its bundled BLAS/LAPACK. HDF5 uses the stable 1.14.6 compatibility series.
Samba is configured for this SysV host with systemd integration disabled; bundled support libraries are private to avoid replacing system talloc.
Optional integrations remain optional. This adds applications, not every optional upstream feature: for example Crow Translate uses Qt speech without the optional neural Piper backend.
Qt5-only applications, mobile-only applications and experimental/beta releases were excluded; see the catalog table below.

INSTALLATION WHEN WANTED
Nothing has been installed by this work. Individual applications can be selected with scratch.
The optional kde-desktop-apps-extra package depends on all 43 new desktop applications; it can be a large build/install.
Scratch dependency resolution does not upgrade dependencies that are already installed. Review/upgrade changed dependencies separately before building applications that use them:
  mpv hdf5 highway opencv python-jinja python-pip python-scour
The existing app installers and the kde6 group were not replaced or made to install all these applications automatically.
